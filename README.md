# Ghumketu Landing

Static HTML landing page.

## Structure

```
ghumketu_landing/
├── index.html
└── assets/
    ├── css/styles.css
    ├── js/main.js
    └── img/
```

## Run locally

Open `index.html` directly, or serve it:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000
